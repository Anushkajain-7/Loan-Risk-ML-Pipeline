THE FINDING
A useful research baseline. Insufficient evidence for lending.
The model ranks risk modestly better than chance on 129 later applications. Its threshold catches all observed bad loans while flagging almost every good loan. A high recall score alone would hide this operational weakness.
Join customer IDs to the loan prefix only after type normalization. Use first-loan suffix -01 to avoid assigning repeat-loan outcomes to an initial application. Two malformed IDs and four unmatched applications are excluded.
New applications must pass identity, affordability, policy, and human review outside this research model. Obtain recent applicants, including declined borrowers where outcomes can be ethically observed, and a defined outcome horizon before expanding use.

DATA MINIMIZATION
Your data, with clear boundaries.
Account email
Stored in the application database for sign-in; not returned in account APIs.
Password
Hashed with Argon2id. Plaintext is used for verification and never persisted or logged.
Application inputs
Financial figures, score values, and coarse account tenure are stored with your assessment, for account-only history and monitoring.
Session
Opaque cookie with HttpOnly and SameSite=Strict. Secure is required in production. Only a keyed token digest is stored.
Optional AI explanation
Opt-in only. Hugging Face receives the risk-band label and three feature names; no names, IDs, score values, financial amounts, or credentials are sent in the prompt.
CONTROLS
Protected by design.
  • Ownership checks on every prediction action.
  • CSRF protection and one explicit origin.
  • Rate limits persisted in the database.
  • Generic errors with correlation IDs.
  • No analytics or browser storage of personal data.
  • API docs and arbitrary file access are disabled.
HTTPS, verified database TLS, disk encryption, backup retention, and deployment configuration require operator verification.
Delete your account
This permanently deletes the live account, sessions, assessments, and outcome feedback. Backup copies expire according to the operator's retention policy.
