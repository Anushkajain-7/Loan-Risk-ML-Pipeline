# Under-60-minute project presentation

Plan: 25-minute presentation, 10 minutes for questions (35 minutes total).

| Time | Topic | What to show/say |
| --- | --- | --- |
| 0-2 min | Problem and success criterion | Predict Bad risk for future origination; avoid unsupported automatic approvals |
| 2-5 min | Dataset and relationships | 647 applications/1,285 loans; numeric-ID repair; first-loan mapping; exclusions |
| 5-8 min | Quality and leakage | 2010-2011 cohort, approved-only selection; no target horizon; remove identities and approval fields |
| 8-11 min | Features and pipeline | 14 inputs, two ratios, train-only preprocessing/scaling/encoding |
| 11-14 min | Experiments | Four candidates, expanding-window CV, frozen-model calibration, separate threshold validation |
| 14-18 min | Results | PNG ROC/PR/calibration charts; AUC0.621; 65 bad caught but62 good flagged; baseline comparison |
| 18-22 min | App demonstration | Create fresh account, synthetic example, score, factors/OOD, outcome, monitoring; optional HF disabled unless configured |
| 22-25 min | Security and next steps | Ownership, privacy flow, secret inventory, actual test evidence, deployment gates, prospective/fairness validation |
| 25-35 min | Questions | Explain ID suffix assumption, threshold cost, calibration uncertainty, and why recall alone is misleading |

Record the actual app window with an operating-system recorder after running it locally. Use only synthetic application values and a disposable account. Hide any environment editor/terminal containing credentials. No video recording has been generated by this project.
